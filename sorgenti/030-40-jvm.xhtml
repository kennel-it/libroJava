JVM

compilare ed eseguire programmi Java

Per far funzionare un programma Java non è necessario avere un ambiente di sviluppo integrato: si può fare tutto installando il JDK (Java Development Kit) ed avere un editor di testo (ad esempio il blocco note di Windows).

Scrittura

Per semplificare un po' le cose creiamo una cartella "prova" sulla scrivania in cui inseriamo un file Saluto.java fatto così:

public class Saluto{
	public static void main(String args[]){
		System.out.println("ciao mondo!");
	}
}

Bisogna assicurarsi che il file si chiami esattamente Saluto.java e non Saluto.java.txt

Compilazione

FIXME: impostare il path di javac in windows

Per fare questo bisogna aprire un terminale ad andare nella cartella in cui si trova il file Saluto.java.

Questo è il nostro file sorgente e va compilato in modo che java possa eseguirlo: il comando da usare è javac seguito dal nome del file da compilare.

$ javac Saluto.java

Se tutto va bene nella cartella comparirà un file in più chiamato Saluto.class che contiene il codice compilato. Guiardando l'elenco dei file contenuti nella cartella dovrebbe comparire:

Saluto.class 
Saluto.java

Interprete

Per eseguire il programma dobbiamo avviare l'interprete javadicendogli quale è il programma da avviare (che in java, guarda caso, si chiama classe), non bisogna mettere il ".class" finale ma soltanto il nome.

java Saluto

In questo caso l'ouput del programma compare direttamente nel terminale.
