La parte in blu si ripete due volte e così il programma risulta più lungo e più soggetto ad errori!

Ma c'è una soluzione: scrivere un metodo che fa il lavoro comune. Questo metodo dovrà leggere sempre dalla stessa casella e avere come risultato un vettore di interi


private int[] leggiDati(){
    String testi[] = valori.getText().split(" ");
    int numeri[] = new int[testi.length];
    for (int i = 0; i < testi.length; i++) {
        numeri[i] = Integer.parseInt(testi[i]);
    }
    return numeri;
}
    
private void trovaMassimo(){
    int numeri[] = leggiDati();
    int massimo;
       
    massimo = numeri[0];
    for (int i = 1; i < numeri.length; i++) {
        if(numeri[i]>massimo){
            massimo = numeri[i];
        }
    }
    risposta.setText(""+massimo);
}

private void calcolaMedia(){
    int numeri[] = leggiDati();
    int somma=0,media;
       
    for (int i = 0; i < numeri.length; i++) {
        somma += numeri[i];
    }
    media = somma/numeri.length;
    risposta.setText(""+media);
}

Rispetto all'esempio precedente potrebbe succedere che l'elenco dei numeri si trovi in una casella oppure in un'altra, in questo caso la nostra funzione non va più bene perché legge sempre dalla stessa casella: potrebbe in questo caso far comodo una funzione che dato un testo (String) costruisca il vettore di numeri.

// dichiarazione della funzione
private int[] daStringaAVettore(String testo){ 
    String testi[] = testo.split(" ");
    int numeri[] = new int[testi.length];
    for (int i = 0; i < testi.length; i++) {
        numeri[i] = Integer.parseInt(testi[i]);
    }
    return numeri;
}

Dalla prima riga della dichiarazione della funzione si possono ricavare alcune informazioni:

int[]
la funzione restituirà (a chi l'ha chiamata) un vettore di interi
daStringaAVettore
il nome della funzione, dovrà essere usato per chiamarla
String testo
la funzione richiede un parametro di tipo String, quel parametro all'interno della funzione sarà riferito come testo (cioè all'interno della funzione potremmo usare una variabile chiamata testo

Poi, per usare la funzione, potremo scrivere qualcosa del tipo:

private void calcolaMedia(){
    String contenutoCasella = valori.getText();
    int numeri[];
    int somma=0,media;
       
    // chiamo la funzione registro il risultato nel vettore numeri 
    numeri = daStringaAVettore(contenutoCasella);
    for (int i = 0; i < numeri.length; i++) {
        somma += numeri[i];
    }
    media = somma/numeri.length;
    risposta.setText(""+media);
}
