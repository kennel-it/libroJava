eventi temporizzati in javafx

Giusto per iniziare...

Proviamo un approccio abbastanza semplice: creo una classe con la finestra che usa un thread per aggiornare una etichetta di testo. La classe che implementa il Thread non fa altro che aggiornare scrivere il numero, aspettare un secondo, decrementare e aggiornare di nuovo.

L'unica parte più intricata è quella che ci serve per perdere un secondo: per adesso la prendiamo così com'è.

public class Timer1 extends Application{
  @Override
  public void start(Stage primaryStage) throws Exception {
    Label testo = new Label("finestra timer");
    Scene scene = new Scene(new BorderPane(testo),200,100);
    primaryStage.setTitle("Timer!"); 
    primaryStage.setScene(scene);
    primaryStage.show();
    Aggiornatore1 a = new Aggiornatore1(testo);
    a.start();
  }
  public static void main(String args[]){
    launch();
  }
}

public class Aggiornatore1 extends Thread{
  Label etichetta;
  public Aggiornatore1(Label etichetta) {
    this.etichetta = etichetta;
  }
  private void perdiUnSecondo(){
    // non ci curiamo particolarmente di come funziona!
    try {
      synchronized (this) { this.wait(1000); }
    } catch (InterruptedException e) {
      e.printStackTrace();
    }
  }
  @Override
  public void run(){
    int n=100;
    while(n>=0){
      etichetta.setText(""+n);
      perdiUnSecondo();
      n--;
    }
  }
}

Il problema è che la soluzione sopra non funziona! L'errore sta nel fatto che la classe Aggiornatore1 tenta di aggiornare l'etichetta ma questo non si può fare perché stiamo lavorando in un thread diverso rispetto a quello di JavaFX. La soluzione è quella di usare il metodo runLater() di Platform In questo modo il codice verrà eseguito nel thread di JavaFX.

Il modo più semplice di farlo è questo:

public void run(){
  while(n>=0){
    Platform.runLater(() -> {
      etichetta.setText(""+n);
    });
    perdiUnSecondo();
    n--;
  }
}

Timeline

Una seconda possibilità è quella di usare l'oggetto Timeline di JavaFX. Questo oggetto insieme a KeyFrame viene usato per creare animazioni che ad esempio spostano oggetti tra due punti sullo schermo, noi lo usiamo più semplicemente per chiamarte una funzione che aggiorna i tempi. Non serve creare un thread perché sarà JavaFX a chiamare la nostra funzione ad intervalli di tempo prefissati.

import javafx.animation.KeyFrame;
import javafx.animation.Timeline;
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Label;
import javafx.scene.layout.BorderPane;
import javafx.stage.Stage;
import javafx.util.Duration;

public class Timer2 extends Application{	
  Label testo;
  int n=100;
	
  @Override
  public void start(Stage primaryStage) throws Exception {
    testo = new Label("finestra timer");
    Scene scene = new Scene(new BorderPane(testo),200,100);
    primaryStage.setTitle("Timer!"); 
    primaryStage.setScene(scene);
    primaryStage.show();
    Timeline timeline = new Timeline(new KeyFrame(
      Duration.seconds(1), // ogni quanto va chiamata la funzione
      x -> aggiornaTimer()));
    timeline.setCycleCount(100);
    timeline.play();
  }

  private void aggiornaTimer(){
    testo.setText(""+ (n--));
  }
	
  public static void main(String args[]){
    launch();
  }
}

Tempi precisi!

Se serve di avere tempi precisi di esecuzione possiamo usare un'altra via: AnimationTimer, questo oggetto ci permette di eseguire del codice ogni volta che la finestra viene aggiornata, non abbiamo degli intervalli precisi ma ci viene passato un parametro che rappresenta il tempo attuale espresso in miliardesimi di secondo.

import javafx.animation.AnimationTimer;
import javafx.application.Application;
import javafx.scene.Scene;
import javafx.scene.control.Label;
import javafx.scene.layout.BorderPane;
import javafx.stage.Stage;

public class Timer3 extends Application{
  private Label testo;
  private AnimationTimer timer;
  private long fine;
	
  @Override
  public void start(Stage primaryStage) throws Exception {
    testo = new Label("finestra timer");
    Scene scene = new Scene(new BorderPane(testo),200,100);
    primaryStage.setTitle("Timer!"); 
    primaryStage.setScene(scene);
    primaryStage.show();
        
    timer = new AnimationTimer() { 
      @Override
      public void handle(long x) {
        aggiornaTimer(x);
      }
    };
    fine = System.nanoTime() + 1_000_000_000 * 100L;
    timer.start();
  }

  private void aggiornaTimer(long t){
    long n = (fine-t) / 1_000_000_000;
    testo.setText(""+n);
    if(n==0){
      timer.stop();
    }
  }
	
  public static void main(String args[]){
    launch();
  }
}
