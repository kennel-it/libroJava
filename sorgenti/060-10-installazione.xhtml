installazione

Procedure per l'installazione di diversi tipi di software: java, eclipse e scene builder.

Java Development Kit

  • aprire con un browser la pagina Java SE Downloads.
  • click sul pulsante download sotto JDK
  • accettare la licenza
  • scaricare la versione giusta per il proprio sistema

eclipse

Le istruzioni che seguono sono per scaricare il pacchetto, non per l'installer.

La versione "EE" ci è utile perché ha anche degli editor per i css.

  • aprire con un browser il sito eclipse.org
  • seguire il link per la pagina dei download
  • seguire il link download packages
  • scaricare la versione "Eclipse IDE for Java EE Developers" giusta per il proprio sistema operativo
  • una volta scaricato eclipse scompattare il file e posizionare la cartella "eclipse" sulla scrivania (o in altra posizione)
  • è possibile lanciare eclipse aprendo la cartella e facendo doppio click sull'eseguibile

e(fx)clipse

È un plugin per eclipse che consente di interagire più facilmente con programmi che usano javafx.

La pagina da cui ottenere informazioni è quella di e(fx)clipse.

Le istruzioni che seguono sono per la versione 2.4.0 .

  • aprire eclipse
  • menu /Help/Install New Software...
  • click sul pulsante "Add..."
  • nel campo "name" inserire "e(fx)clipse"
  • nel campo "location" inserire "http://download.eclipse.org/efxclipse/updates-released/2.4.0/site"
  • click sul pulsante "ok"
  • nella casella "work with" deve comparire il sito appena immesso
  • al centro della finestra selezionare il gruppo "e(fx)clipse install"
  • premere "next>" e completare l'installazione (anche accettando la licenza)
  • alla fine dell'installazine verrà richiesto il riavvio di eclipse

Scene Builder

È un programma che permette di costruire velocemente interfacce per JavaFX.

Durante l'installazione è bene prendere nota della cartella in cui viene installato Scene Builder.

  • aprire con un browser la pagina Gluon: Scene Builder.
  • click sul pulsante download
  • scaricare la versione corretta per il proprio sistema operativo
  • installare il programma appena scaricato

Il programma viene installato nella cartella AppData dell'utente... che normalmente windows tiene nascosta, per poterla vedere bisogna aprire Esplora risorse e nel gruppo Mostra/Nascondi della linguetta Visualizza bisogna spuntare "elementi nascosti"

Per poter usare Scene Builder direttamente da Eclipse:

  • aprire eclipse
  • menu Windows/Preferences
  • selezionare sulla sinistra il gruppo "JavaFX"
  • nella parte centrale compare "Scene Builder executable"
  • fare click su browse e trovare Scene Builder nel proprio sistema

Solitamente il percorso di Scene Builder è C:\Users\NOME_DELL_UTENTE\AppData\Local\SceneBuilder\SceneBuilder.exe
